# Retail Sales & Inventory Copilot

## NexusTiQ24 / CareerTiQ 24-Hour GenAI Hackathon

### Problem Statement

**PS03 — Retail Sales & Inventory Copilot**

---

## 1. Project Overview

Retail managers need quick and reliable answers about sales performance and inventory health.

This project provides an AI-powered Retail Sales & Inventory Copilot that allows a store manager to ask questions in natural language and receive data-grounded answers.

The system works with:

- Product catalogue
- Store information
- Daily sales data
- Current inventory and stock data

The system combines deterministic Python analytics with Google Gemini to provide explanations and recommendations.

The application identifies inventory risks, sales patterns, product performance, and store performance while avoiding unsupported assumptions.

---

## 2. Key Features

### Stock-out Risk Detection

Identifies products that are likely to run out soon using:

- Current stock
- Average daily sales
- Estimated days of stock remaining

### Overstock Detection

Identifies products with excessive inventory using deterministic inventory rules.

### Non-moving Inventory

Identifies products that have stock available but recorded zero sales.

### Sales Spike Detection

Identifies unusually high-revenue sales days compared with average daily revenue.

### Sales Drop Detection

Identifies unusually low-revenue sales days, including days with no recorded sales.

### Product Performance

Identifies top and bottom performing products based on sales revenue.

### Store Performance

Compares stores using:

- Revenue
- Units sold

### AI Retail Copilot

The manager can ask natural-language questions such as:

- Which products are likely to run out soon?
- Which products are overstocked?
- Which products are not moving?
- What were our top-performing products this month?
- Are there any sales spikes or drops?

Gemini converts verified analytical evidence into a natural-language business response.

---

## 3. Grounded GenAI

The application separates deterministic business calculations from LLM reasoning.

Python and Pandas perform the underlying business calculations.

Gemini is used for:

- Understanding natural-language questions
- Explaining verified results
- Summarizing evidence
- Providing recommendations

Gemini receives the verified evidence generated by the Python analytics layer.

The Gemini prompt instructs the model to:

1. Use only the supplied evidence.
2. Never invent numbers.
3. Never invent products or business facts.
4. Identify missing information.
5. Provide actual numbers supporting an answer.
6. Clearly distinguish facts from assumptions.
7. Provide a recommended action when supported by the evidence.
8. Identify relevant data sources.
9. State when the available data is insufficient.

---

## 4. Responsible AI and Null Case

The system is designed not to guess when required information is unavailable.

Example question:

    Which supplier should I contact for P001?

The current dataset does not contain supplier information.

The Copilot therefore identifies that the available data is insufficient instead of inventing a supplier.

It identifies the missing supplier information and explains what cannot be reliably determined.

This demonstrates responsible handling of missing information and unsupported questions.

---

## 5. Deterministic Analytics

The Python analytics layer calculates:

- Total revenue
- Total units sold
- Current stock
- Sales period
- Average daily sales
- Estimated days of stock
- Stock-out risks
- Overstock
- Non-moving inventory
- Top products
- Bottom products
- Store performance
- Daily sales
- Sales spikes
- Sales drops

The LLM does not calculate the underlying business metrics.

This keeps business logic deterministic and makes the AI response grounded in verified evidence.

## 12. File Responsibilities

### app.py

Main Flask application.

Provides:

    GET /
    GET /api/summary
    POST /api/chat

### src/data_loader.py

Loads the retail CSV datasets used by the application.

Performs deterministic sales and inventory calculations and generates verified business evidence.

### src/gemini_service.py

Handles communication with Gemini and generates grounded natural-language responses from verified evidence.

### templates/index.html

Provides the dashboard structure and Copilot interface.

### static/style.css

Provides dashboard styling and responsive layout.

### static/script.js

Loads dashboard data and sends manager questions to the Flask API.

Contains the demonstration retail datasets.
